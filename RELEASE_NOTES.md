# Pocket Lab 0.2.0

Kino der Toten now runs Black Ops' own zombies scripts instead of a bare walk-around.

**New**
- You spawn at Kino's real start point in the lobby with the M1911, given by the game's own scripts.
- Points and the round number on screen (top left: round, top right: points). You start with 500 like in Black Ops.
- Wall buys work: walk up to a chalk outline, look at it and press USE. The Olympia by the start costs 500: the gun slides out of the wall and the points are taken.
- FIRE, AIM and RELOAD work with the guns you hold.

**Not yet**
- No zombies: the rounds run, but nobody spawns, so there is no way to earn points yet.
- No "Hold USE to buy" hint text, no doors or perks tested, no menus.
- Some sounds are missing.

**From 0.1.4**
- Touch buttons answer where they are drawn; two frames in flight for smoother movement; fullscreen at the screen's own size.

**Setup**
1. Install `Pocket.Lab.ipa` over the existing Pocket Lab (do not delete the app: that deletes the game files).
2. First time only: copy the staged `Call of Duty Black Ops` folder (`scripts/stage-bo1-for-iphone.ps1`) into Pocket Lab's folder (Apple Devices → Files → Pocket Lab).
3. Open Pocket Lab and stay in the app until the map shows.

Problem reports: `iw4l-boot.log` from the app's folder.
